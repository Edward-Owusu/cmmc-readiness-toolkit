Action plan

  1. AC.L1-B.1.II Transaction and Function ControlQuick win
    • Not in place. Have you defined what each type of user is allowed to do (for example, only administrators can install software or change settings)? No written roles.
    • Not in place. Are everyday users prevented from having administrator rights on their computers? Several office users have local administrator rights.

    Fix: Define user roles, remove administrator rights from everyday accounts, and give administrators a separate account for admin work.

  2. AC.L1-B.1.I Authorized Access ControlQuick win
    • Only partly in place. Do you keep a list of the devices (computers, phones, servers) allowed to connect to those systems? Office computers are listed; shop-floor PCs and personal phones are not.

    Fix: Create and maintain a list of authorized users and devices, turn off guest and anonymous access, and require a sign-in on every system that holds FCI.

  3. AC.L1-B.1.IV Control Public InformationQuick win
    • Only partly in place. Is public content reviewed to make sure it contains no FCI, both before posting and periodically afterward? Reviewed before posting, but no periodic review.

    Fix: Name who may post public content, require review for FCI before anything is published, and check existing public content periodically.

  4. IA.L1-B.1.V IdentificationQuick win
    • Not in place. Does every person have their own user account, with no shared logins? Shop floor uses a shared 'floor.kiosk' login.

    Fix: Replace shared logins with individual accounts and record every device and service account with a unique name.

  5. IA.L1-B.1.VI AuthenticationQuick win
    • Only partly in place. Are default passwords on new devices, software, and equipment changed before they are used? Changed on computers but not on the shop printer and two network switches.

    Fix: Require authentication on every system and change all default passwords; adding multi-factor authentication is strongly recommended and is required at Level 2.

  6. PE.L1-B.1.IX Manage Visitors and Physical AccessQuick win
    • Only partly in place. Do you control keys, badges, and lock combinations: knowing who has them, collecting them when people leave, and changing combinations when needed? Keycards are issued but not always collected from departing staff.

    Fix: Escort visitors, keep a sign-in log, and track who holds keys and badges, collecting them at departure.

  7. SI.L1-B.1.XII Flaw RemediationQuick win
    • Only partly in place. Do you install security updates for operating systems and software within a set time frame? Office PCs update automatically; the file server and shop PCs are patched irregularly.

    Fix: Turn on automatic updates where possible, subscribe to vendor security alerts, and set a time frame for installing critical updates.

  8. SI.L1-B.1.XIII Malicious Code ProtectionQuick win
    • Only partly in place. Is antivirus or endpoint protection installed on every computer and server? Two shop-floor PCs have no antivirus.

    Fix: Deploy endpoint protection on every computer and server, and turn on malware and phishing filtering for email.

  9. AC.L1-B.1.III External ConnectionsProject
    • Not in place. Have you identified the outside systems people use for company work, such as personal devices, home computers, cloud services, and customer or partner portals?
    • Not in place. Do you control or limit those connections, for example by allowing company data only on approved devices and services? Employees use personal phones and home PCs for email without restriction.

    Fix: List the external systems and services in use, approve the ones that are needed, and block or restrict company data on everything else.

  10. SC.L1-B.1.X Boundary ProtectionProject
    • Not in place. Is the firewall set to block unnecessary incoming traffic, and are its settings and logs reviewed? Default rules; nobody reviews logs.

    Fix: Put a business-grade firewall at the internet edge, block all inbound traffic that is not needed, and review its rules and alerts regularly.
