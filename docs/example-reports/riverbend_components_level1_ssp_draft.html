2. Requirement implementation

AC.L1-B.1.I Authorized Access Control

Limit information system access to authorized users, processes acting on behalf of authorized users, or devices (including other information systems). (52.204-21(b)(1)(i); NIST SP 800-171 3.1.1)

Status
NOT MET
Implementation
User accounts are managed in Microsoft 365 and on the domain controller; the IT manager keeps the list. All computers require Windows sign-in; Microsoft 365 requires sign-in.
Evidence
Microsoft 365 user export
Gaps
Only partly in place. (AC1-2) Office computers are listed; shop-floor PCs and personal phones are not.
Planned action
Create and maintain a list of authorized users and devices, turn off guest and anonymous access, and require a sign-in on every system that holds FCI.

AC.L1-B.1.II Transaction and Function Control

Limit information system access to the types of transactions and functions that authorized users are permitted to execute. (52.204-21(b)(1)(ii); NIST SP 800-171 3.1.2)

Status
NOT MET
Implementation
Implementation description to be completed.
Gaps
Not in place. (AC2-1) No written roles. | Not in place. (AC2-2) Several office users have local administrator rights.
Planned action
Define user roles, remove administrator rights from everyday accounts, and give administrators a separate account for admin work.

AC.L1-B.1.III External Connections

Verify and control/limit connections to and use of external information systems. (52.204-21(b)(1)(iii); NIST SP 800-171 3.1.20)

Status
NOT MET
Implementation
Implementation description to be completed.
Gaps
Not in place. (AC3-1) | Not in place. (AC3-2) Employees use personal phones and home PCs for email without restriction.
Planned action
List the external systems and services in use, approve the ones that are needed, and block or restrict company data on everything else.

AC.L1-B.1.IV Control Public Information

Control information posted or processed on publicly accessible information systems. (52.204-21(b)(1)(iv); NIST SP 800-171 3.1.22)

Status
NOT MET
Implementation
The office manager approves website and social posts.
Gaps
Only partly in place. (AC4-2) Reviewed before posting, but no periodic review.
Planned action
Name who may post public content, require review for FCI before anything is published, and check existing public content periodically.

IA.L1-B.1.V Identification

Identify information system users, processes acting on behalf of users, or devices. (52.204-21(b)(1)(v); NIST SP 800-171 3.5.1)

Status
NOT MET
Implementation
Devices are named by location.
Gaps
Not in place. (IA1-1) Shop floor uses a shared 'floor.kiosk' login.
Planned action
Replace shared logins with individual accounts and record every device and service account with a unique name.

IA.L1-B.1.VI Authentication

Authenticate (or verify) the identities of those users, processes, or devices, as a prerequisite to allowing access to organizational information systems. (52.204-21(b)(1)(vi); NIST SP 800-171 3.5.2)

Status
NOT MET
Implementation
Passwords required for all accounts.
Gaps
Only partly in place. (IA2-2) Changed on computers but not on the shop printer and two network switches.
Planned action
Require authentication on every system and change all default passwords; adding multi-factor authentication is strongly recommended and is required at Level 2.

Status
MET

PE.L1-B.1.VIII Limit Physical Access

Status
MET

PE.L1-B.1.IX Manage Visitors and Physical Access

Escort visitors and monitor visitor activity; maintain audit logs of physical access; and control and manage physical access devices. (52.204-21(b)(1)(ix); NIST SP 800-171 3.10.3, 3.10.4, 3.10.5)

Status
NOT MET
Implementation
Visitors are escorted. Front desk sign-in sheet.
Evidence
Visitor log binder
Gaps
Only partly in place. (PE2-3) Keycards are issued but not always collected from departing staff.

SC.L1-B.1.X Boundary Protection

Monitor, control, and protect organizational communications (i.e., information transmitted or received by organizational information systems) at the external boundaries and key internal boundaries of the information systems. (52.204-21(b)(1)(x); NIST SP 800-171 3.13.1)

Status
NOT MET
Implementation
Office firewall at the internet edge.
Gaps
Not in place. (SC1-2) Default rules; nobody reviews logs.
Planned action
Put a business-grade firewall at the internet edge, block all inbound traffic that is not needed, and review its rules and alerts regularly.
